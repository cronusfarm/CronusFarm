CronusFarm — R3/R4 부팅 시 2004A 패널 LCD 표시 순서

빌드 기준: R4→R3 UART(19200, Serial1 / R3 SoftwareSerial). I2C 슬레이브는 백그라운드로 동작하나 LCD 본문은 UART가 우선입니다.

① R3 전원 직후 (CronusFarmPanel.ino setup)

1행CronusFarm Panel
2행공백(빈 줄)
3·4행lcd.clear() 직후 빈 화면

부저 짧게 두 번. BOOT_MSG_MS = 10초 동안 R4가 LCD 명령을 안내면 이후 R3 로컬 환영으로 전환(아래 ②).

② R3만 있고 R4 UART가 10초 이상 없을 때 (한 번만)

1행Welcome 2 CronusFarm
2행----.--.-- (---) (R3 RTC 미연동 초기값)
3행--:--:--
4행공백

R4가 UART로 L,/C를내면 masterOwnsLcd가 되어 ②가 스킵될 수 있습니다.

③ R4 동작 후 (일반)

③-a WiFi 연결 전 (lcdRenderUi 대기)

1행첫 채널 예: LED A1 D2 (gUiCh=0)
2행WiFi -- MQTT -- 등(포맷 %s %s로 WiFi와 MQTT 사이 공백 두 칸)
3행Waiting link...
4행공백

③-b WiFi 연결 직후 (lcdWelcomeIfOk 1회)

1행Welcome to
2행CronusFarm
3행RTC 날짜
4행RTC 시각 + AM/PM

③-c 환영 후 5초 동안

③-b와 동일. 1초마다 3·4행만 RTC로 갱신. 브라우즈 4줄은 아직 안 그림.

③-d 환영 5초 경과 후 — 브라우즈

1행채널명 + 핀 (예: LED A1 (D2))
2행MODE:AUTO / MODE:MAN
3행STATE:… CHn/15
4행DIAL Next PUSH Edit

③-e EDIT 모드

  • Setting Mode (EDIT) / 채널·핀 / SET:OFF|ON|AUTO / Dial:Sel Push:OK

참고

  • R3 환영 문구와 R4 환영 문구는 서로 다릅니다.
  • 전원 순서(R3 먼저 / R4 먼저)에 따라 ①·②가 잠깐 보이다가 ③으로 바뀔 수 있습니다.
